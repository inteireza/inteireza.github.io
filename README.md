# Inteireza

Landing page da Imersão Inteireza, em HTML, CSS e JavaScript, pronta para GitHub Pages.

## Publicar

1. Crie um repositório chamado `inteireza` na sua conta GitHub e envie o conteúdo desta pasta para a branch `main`. No GitHub Free, use um repositório público para habilitar Pages.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/docs**, e salve.
5. Aguarde a publicação. O endereço exato aparecerá nesse painel, normalmente `https://SEU-USUARIO.github.io/inteireza/`.

Nenhum domínio próprio é necessário. Este pacote não altera o domínio ou o site de Shirley Ortiz na Wix.

O nome `inteireza` identifica o projeto. Um endereço exatamente `inteireza.github.io` depende de possuir a conta ou organização GitHub chamada `inteireza`. Um domínio como `inteireza.com.br` precisa ser registrado separadamente e configurado no Pages.

## Editar e visualizar

Os arquivos públicos estão em `docs/`. Edite `docs/index.html` para alterar textos, datas, preços e contatos; `docs/styles.css` para o visual; e `docs/script.js` para os efeitos de entrada. O PDF e as imagens estão em `docs/assets/`.

Abra `docs/index.html` diretamente no navegador ou execute:

```bash
python3 -m http.server 8000 --directory docs
```

## Conteúdo publicado

Inclui a foto fornecida pelo usuário, os florais do PDF, a apresentação original para download, o link de inscrição e os contatos profissionais das facilitadoras. Nenhuma credencial é necessária no código. Formulário e WhatsApp são externos.
